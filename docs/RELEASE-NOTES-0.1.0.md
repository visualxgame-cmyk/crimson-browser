Prima versiune publică Vela pentru Windows x64.

- Mod economic, taburi încărcate la cerere și protejarea formularelor, redării audio și descărcărilor.
- Logo-uri pentru site-uri în New Tab, scurtături editabile, profiluri separate și grupuri de taburi.
- Favorite cu import, lista Citește mai târziu, istoric, căutare în pagină și export PDF.
- Backup/sincronizare criptate prin folder și măsurători RAM/CPU la cerere.
- Repository-ul pentru verificarea manuală a actualizărilor este preconfigurat.

Instalatorul și arhiva portabilă includ .NET. Este necesar Microsoft Edge WebView2 Runtime. Arhiva portabilă trebuie extrasă complet; datele browserului se păstrează în profilul Windows.

Pachetele sunt nesemnate digital. `release-manifest.json` permite verificarea integrității SHA-256, fără a înlocui semnătura editorului. Păstrează protecțiile Windows active.

Verificări: suită automată în profil izolat, descărcare locală de 64 MB, recuperare după oprire forțată, izolare cookie-uri/profiluri și teste publice Wikipedia, Microsoft Learn, YouTube și video HTTPS. Autentificările reale, streamingul DRM, apelurile cu cameră/microfon și toate configurațiile Windows/monitoare nu sunt validate integral.
