Corecție pentru ecran complet.

- Solicitările fullscreen ale paginilor Web, inclusiv playerul YouTube, sunt preluate din evenimentul nativ WebView2 și extind corect fereastra Vela.
- În fullscreen sunt ascunse bara de taburi, toolbarul, bara de permisiuni și bara de stare; conținutul paginii rămâne pe rândul principal și ocupă întreaga fereastră.
- La ieșirea din fullscreen, interfața revine exact la starea normală. `F11` rămâne disponibil pentru fullscreen-ul browserului, iar `Esc` este lăsat playerului pentru ieșirea din fullscreen-ul paginii.

Pachetele includ .NET și necesită Microsoft Edge WebView2 Runtime. Rămân nesemnate digital, conform opțiunii curente a proiectului. Manifestul SHA-256 verifică integritatea fișierelor.
