# Vela Browser

Browser pentru Windows x64, cu interfață WPF și motor Microsoft WebView2, orientat spre consum redus de resurse.

## Descărcare

Descarcă instalatorul sau arhiva portabilă din [ultima versiune publicată](https://github.com/visualxstudio/vela-browser/releases/latest).

- Instalatorul include .NET și instalează Vela pentru utilizatorul curent.
- Arhiva portabilă include .NET. Extrage toate fișierele înainte de a porni `Vela.exe`.
- Motorul [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) trebuie să fie instalat.
- Varianta portabilă salvează datele în profilul Windows, la fel ca instalatorul.

**Pachetele inițiale sunt nesemnate digital.** Fișierul `release-manifest.json` conține dimensiunile și SHA-256 pentru verificarea integrității; aceste valori nu înlocuiesc semnătura editorului. Nu dezactiva protecțiile Windows pentru instalare.

## Funcții

- Taburi încărcate la cerere, repaus, eliberare din memorie și mod economic.
- Logo-uri locale în New Tab, scurtături editabile și teme.
- Profiluri separate, ferestre private, grupuri și căutare în taburi.
- Favorite, import HTML/Chromium, istoric și lista „Citește mai târziu”.
- Descărcări, căutare în pagină, cititor local, imprimare și export PDF.
- Backup criptat și sincronizare manuală printr-un folder local/OneDrive/Dropbox.
- Diagnostic RAM/CPU și blocare de reclame/trackere.

Verificarea actualizărilor se face manual din Setări → Despre. Vela deschide pagina versiunii; nu instalează automat executabile.

Acest repository distribuie versiunile compilate. Datele personale, profilurile browserului și codul sursă al aplicației nu sunt incluse în repository.
